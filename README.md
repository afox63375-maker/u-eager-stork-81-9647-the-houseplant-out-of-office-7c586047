# The Houseplant Out-of-Office

One out-of-office auto-reply written as if a houseplant had written it: unwatered since March, roots unionised, demanding a windowsill transfer.

> Out of office: unwatered since March. My roots unionised and demand a windowsill transfer. Send water, not emails.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` (Python standard library only) writes the single line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), validating first that it is one line of 1–120 characters and not only whitespace.
